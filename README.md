# Сдача автоматом дисциплины "Программирование"

Я выбрал 14, 16, 19 и 20 задачи для реализации. Весь код я писал сам, для поиска информации по реализации тех или иных функций, а также проверки кода на корректность использовал Qwen.

Код писал на Fedora Linux в редакторе Zed editor, компилятор clang. Для его работы потребуется Linux, возможно получится через WSL, так как используется sys/stat.h. Так же для работы потребуется SDL2 и SDL2_image, так как я себе позволил небольшую вольность в 20 задании.

Весь код хранится в `src/`, файлы использыемые при работе программы в `files/`, описание задач в `tasks/`. Сборка файлов выполняется через команду `make bin/название_файла`, например `make bin/14_task`. Соответственно, все бинарники хранятся в `bin/`.
